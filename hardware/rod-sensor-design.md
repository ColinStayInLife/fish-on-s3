## 二、推荐方案 A 详细设计

### 2.1 接线

```
┌──────────────────────────────────────────────┐
│  ESP32-C3 超小板                             │
│                                              │
│  3.3V ─────┬──── MPU6050 VCC                 │
│  3.3V ─────┴──── CR2032 电池 (+)             │
│  GND  ───────── MPU6050 GND  / 电池 (-)      │
│  GPIO5 ──────── MPU6050 SCL (I2C时钟)       │
│  GPIO6 ──────── MPU6050 SDA (I2C数据)       │
│                                              │
│  🔌 USB-C：初次烧录用，烧完就不需要了          │
└──────────────────────────────────────────────┘
```

**只需 4 根线！**（VCC、GND、SCL、SDA）

### 2.2 尺寸

```
ESP32-C3 板:  21mm × 18mm × 3mm
MPU6050 模块: 15mm × 20mm × 2mm
CR2032 电池:  20mm × 3mm

叠起来 ≈ 30mm × 25mm × 8mm
热缩管一包 → 一根小手指大小
```

### 2.3 功耗

| 状态 | 电流 | 续航（CR2032 230mAh） |
|:----|:----|:---------------------|
| 深睡（无鱼口） | ~10μA | **~2万小时（2年）** |
| 检测中（100Hz采样） | ~15mA | ~15小时 |
| BLE广播（有鱼口） | ~20mA | ~11小时 |

**实际：平时深睡，加速度变化 > 阈值才唤醒**
→ 一次出钓 8-10 小时，绰绰有余

### 2.4 安装方式

```
鱼竿俯视图：

          ┌─────────────────────────────┐
          │  子机（包热缩管）            │
          │  ┌───────┐                  │
   竿梢 ──┤  │ ESP   │  ┌─────┐        │
          │  │ C3    │  │MPU  │        │
          │  │       │  │6050 │        │
          │  └───────┘  └─────┘        │
          │         CR2032              │
          └─────────┬───────────────────┘
                    │ 弹性绑带/橡皮筋固定
                    ▼
          ┌─────────────────────────────┐
          │       鱼竿竿节             │
          └─────────────────────────────┘

安装位置：离竿梢最近的导环下方竿节处
固定方式：弹性橡胶圈 / 防水胶带 / 3D打印卡扣
```

## 三、固件设计

### 3.1 工作循环

```c
void loop() {
    // 1. 读取 IMU
    imu.readAccel(&ax, &ay, &az);
    
    // 2. 计算振动幅度
    magnitude = sqrt(ax² + ay² + az²) - GRAVITY;
    
    // 3. 状态机判断
    switch(state) {
        case SLEEP:
            if (magnitude > WAKE_THRESHOLD)   // 竿梢动了
                state = DETECT;
            else
                deepSleep(100ms);              // 省电
            break;
            
        case DETECT:
            recordVibration(magnitude);        // 记录波形
            if (magnitude > FISH_THRESHOLD && duration > 2s)
                state = ALERT;
            if (magnitude < IDLE_THRESHOLD > 5s)
                state = SLEEP;
            break;
            
        case ALERT:
            bleAdvertise(rodId, FISH_BIG);     // 广播：大鱼
            break;
    }
}
```

### 3.2 BLE 广播包格式（最小化）

```
广播内容（31字节，控制在极小范围）：
┌────────┬────────┬────────┬────────┐
│ 竿ID   │ 状态码 │ 幅度   │ 电池   │
│ 1 byte │ 1 byte │ 1 byte │ 1 byte │
└────────┴────────┴────────┴────────┘
总数据 = 4 字节，一次广播 0.5ms

状态码:
0x00 = 待命/静默
0x01 = 疑似（小鱼闹窝）
0x02 = 中鱼
0x03 = 爆口（大鱼）
```

## 五、为什么不选更便宜的方案

| 方案 | 单价 | 问题 |
|:----|:----|:-----|
| ESP32-C3 + MPU6050 ✅ | **¥12** | 开发友好，Arduino直接写 |
| 合宙Air001 + HM-10 | ¥8 | 两个芯片焊接麻烦，不支持OTA |
| 只用干簧管（磁铁） | ¥3 | 只能检测有/无，没有幅度/频率分析 |
| 只用振动开关（SW-180） | ¥2 | 不能区分大鱼小鱼，误报率高 |

¥12 已经是最优性价比了，往下降那 ¥4 会损失开发效率和多竿区别能力。
