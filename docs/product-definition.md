# 🎣 FishOn-S3 — 多竿智能鱼口监控系统

## 产品定义说明书

> 版本: V1.0 | 状态: 概念设计 | 日期: 2026-04-28

---

## 一、产品概述

### 1.1 一句话定义
**一套基于 M5Stack CoreS3 SE 的多竿智能鱼口监控系统，用 IMU 传感器 + BLE 无线传输，让钓鱼人一个屏幕看所有竿的鱼口状态。**

### 1.2 解决的核心痛点
| 痛点 | 解决方案 |
|:----|:---------|
| 海竿阵5-8根竿看不过来 | 一个屏幕显示所有竿状态 |
| 夜钓看不清竿梢抖动 | 屏幕+震动+声音三重提醒 |
| 分不清小鱼闹窝还是大鱼咬钩 | IMU智能分析振动模式 |
| 跑鱼了不知道哪竿中的 | 每竿独立信号 + 历史记录 |
| 天气/潮汐影响鱼口 | 集成气象数据，推荐出钓时机 |

### 1.3 系统架构

```
┌─────────────────────────────────────────────────────────┐
│                      FishOn-S3 系统                       │
├───────────────┬─────────────────────────────────────────┤
│   竿梢子机 × 1-8  │          桌面主机 × 1                 │
│                 │                                         │
│  [ESP32-C3]     │  [M5Stack CoreS3 SE]                    │
│  ├─ MPU6050 IMU │  ├─ 1.9" 触控彩屏                       │
│  ├─ BLE发射     │  ├─ MPU6886 IMU (自测/校准用)           │
│  ├─ 纽扣电池    │  ├─ BLE扫描 → 接收所有竿信号            │
│  └─ 防水外壳    │  ├─ WiFi → 气象/飞书推送                │
│                 │  ├─ 喇叭/震动 → 提醒                    │
│                 │  ├─ SD卡 → 渔获日志                     │
│                 │  └─ 触摸交互 → 静音/标记/设置           │
└───────────────┴─────────────────────────────────────────┘
```

## 二、硬件系统定义

### 2.1 桌面主机 — M5Stack CoreS3 SE（已有）

| 组件 | 规格 | 钓鱼项目中的用途 |
|:----|:-----|:----------------|
| **MCU** | ESP32-S3 双核 240MHz | 信号处理 + UI渲染 + BLE扫描 |
| **IMU** | MPU6886 (6轴) | 模式识别算法开发 / 竿梢信号自测 |
| **屏幕** | 1.9" IPS 320×170 触摸 | **鱼口仪表盘** |
| **BLE** | Bluetooth 5.0 | 接收 1-8 根竿梢信号 |
| **WiFi** | 2.4GHz 802.11 b/g/n | 获取气象数据 / 推送飞书通知 |
| **喇叭** | 内置 | 鱼口声音提醒（可自定义音色） |
| **麦克风** | 内置 | （预留）声控操作 |
| **SD卡槽** | TF卡 | 存储渔获日志、配置 |
| **电池** | 内置锂电池 | 户外续航 3-5 小时 |
| **RTC** | BM8563 | 自动校时，打点记录 |

### 2.2 竿梢子机 — BLE振动传感器（单竿 ¥5-15）

| 组件 | 规格 | 单价 | 说明 |
|:----|:-----|:----|:-----|
| **主控** | ESP32-C3 | ~¥6 | 国产，BLE原生支持，超低功耗 |
| **IMU** | MPU6050 | ~¥3 | 6轴加速度+陀螺仪，检测竿梢抖动 |
| **供电** | CR2032 纽扣电池 | ~¥1 | 续航约 200 小时（持续工作） |
| **外壳** | 3D打印 / 热缩管 | ~¥2 | IPX4 防水 |
| **组装** | 手工焊接 | ~¥2 | 简单4个焊点 |
| **合计** | | **~¥14/竿** | 8竿 × ¥14 ≈ ¥112 |

**替代方案（更省事）：**
直接用 **HM-10 BLE模块** (~¥3) + **MPU6050** (~¥3)，用 STM8 或 ATTiny 驱动，成本更低但开发稍麻烦。

### 2.3 安装方式

```
竿梢子机安装位置：
┌─────────────────────────────────┐
│                                 │
│  ┌──────┐    ┌────────────────┐ │
│  │ 竿梢  │    │  子机 (夹在导环  │ │
│  │      │    │  下方竿节上)   │ │
│  └──────┘    └────────────────┘ │
│                                 │
│  ← ← 振动传导方向 → →            │
│                                  │
└─────────────────────────────────┘
    鱼竿（海竿/抛竿/筏竿）
```

**固定方式**：弹性绑带 + 热缩管包裹，绑在离竿梢最近的大导环下方竿节处。

## 三、核心功能定义

### 3.1 功能矩阵

| 功能 | 优先级 | 复杂度 | 说明 |
|:----|:------|:------|:-----|
| **多竿监测** | P0 | ⭐⭐ | BLE扫描8根竿梢信号 |
| **鱼口检测** | P0 | ⭐⭐⭐ | IMU振动模式分析 |
| **大鱼/小鱼区分** | P0 | ⭐⭐⭐⭐ | AI模式识别 |
| **声光报警** | P0 | ⭐ | 不同鱼种不同提醒 |
| **仪表盘显示** | P0 | ⭐⭐ | 所有竿状态一览 |
| **历史记录** | P1 | ⭐⭐ | 渔获日志存储 |
| **气象集成** | P1 | ⭐⭐ | 气压+潮汐+最佳时间 |
| **飞书推送** | P2 | ⭐⭐ | 重大鱼口远程通知 |
| **快速标记录鱼** | P1 | ⭐ | 钓到鱼一键记录 |
| **灵敏度调节** | P1 | ⭐⭐ | 针对不同鱼种调参 |

### 3.2 鱼口检测算法（核心）

```
竿梢抖动 → MPU6050采样(100Hz)
         ↓
┌─────────────────────┐
│  时域特征提取        │
│  - 峰值幅度          │
│  - 抖动频率          │
│  - 能量积分          │
│  - 振动衰减速率      │
└─────────┬───────────┘
          ↓
┌─────────────────────┐
│  模式分类            │
│                      │
│  幅度 < 0.3g ──── 小鱼闹窝（忽略/低优先级提醒）
│  幅度 0.3-1.5g ── 中小鱼试探（闪烁提醒）
│  幅度 1.5-4g ──── 中鱼猛口（声音+震动）
│  幅度 > 4g ────── 大鱼爆口（紧急提醒+飞书）
│                       │
│  频率 1-5Hz ──── 抖动/试探
│  频率 5-20Hz ──── 剧烈挣扎
│  频率 >20Hz ──── 风/水流误报
└─────────────────────┘
```

### 3.3 鱼口状态机

```
                ┌─────────┐
                │  待命中  │ ← 初始状态
                └────┬────┘
                     │ 检测到振动
                     ↓
                ┌─────────┐
         ┌─────│ 可疑信号 │─────┐
         │     └────┬────┘     │
         │          │          │
         │      持续振动       │ 单次振动+停止
         │          │          │
         ↓          ↓          ↓
    ┌────────┐ ┌─────────┐ ┌──────┐
    │ 小鱼闹窝│ │  中鱼   │ │ 误报 │
    ├────────┤ ├─────────┤ ├──────┤
    │ 黄灯   │ │ 红灯+声 │ │ 忽略  │
    │ 低频闪 │ │ 高频闪  │ │      │
    └────────┘ └────┬────┘ └──────┘
                    │ 确认中鱼
                    ↓
              ┌──────────┐
              │ 搏斗中   │ ← 持续监测直到收竿
              └────┬─────┘
                   │ 用户标记"已收竿"
                   ↓
              ┌──────────┐
              │ 日志记录  │ ← 时间/竿号/鱼种/天气
              └────┬─────┘
                   ↓
              ┌──────────┐
              │  待命中   │ ← 复位
              └──────────┘
```

### 4.2 颜色编码系统

| 颜色 | 含义 | 动作 |
|:----|:----|:-----|
| 🟢 **绿色** | 待命中，一切正常 | 无需操作 |
| 🟡 **黄色** | 可疑信号/小鱼闹窝 | 看一眼即可 |
| 🔴 **红色** | 中鱼！需要处理 | 立即起竿 |

### 4.3 操作流程

```
设置模式:
  触摸[设置] → 竿数设置(1-8) → 每竿命名(可选)
          → 灵敏度(高/中/低) → 音量 → 保存

日常使用:
  开机 → 自动连接已配对的竿梢子机
       → 进入仪表盘界面
       → 检测到信号 → 颜色变化 → 报警
       → 起竿 → 触摸[标记渔获] → 选鱼种(可选) → 记录
       → 放回竿 → 自动复位
```

## 五、使用场景详细说明

### 场景一：海竿阵夜钓 🎣🌙

**背景**：周末去水库夜钓，架了6根海竿，天太黑看不清哪根竿梢在动。

**FishOn-S3 使用流程**：
```
19:00 — 到达钓点，架竿
19:10 — 安装6个子机到竿梢
19:15 — 打开CoreS3 SE → 自动扫描 → 6根竿全部连上 ✅
19:20 — 正常开钓
...
20:45 — 屏幕亮红灯！竿3 🔴 "中鱼！0.3s前"
         — 喇叭发出短促提示音
         — 屏幕自动显示竿3的实时振动波形
         — 跑过去收竿，钓上一条3斤鲤鱼
         — 触摸[标记渔获] → 选"鲤鱼" → 自动记录时间20:45
         — 竿3自动复位
...
02:30 — 4根竿同时有信号
         — 屏幕逐条显示
         — 判断竿2是大鱼爆口（幅度>4g）
         — 优先处理竿2 → 钓获大草鱼
02:35 — 标记渔获后继续钓
...
06:00 — 收竿
06:05 — 查看[日志] → 今晚战绩：
         鲤鱼×3, 草鱼×1, 鲫鱼×5
         小鱼闹窝×12次（已自动过滤）
```

**对比没有 FishOn-S3**：
- ❌ 每隔10分钟要用手电筒扫一遍竿梢
- ❌ 夜灯照不到远处竿
- ❌ 错过至少30%的鱼口
- ❌ 分不清哪根竿在动

---

### 场景二：多竿守大物 🐟🔥

**背景**：专守大鱼，同时架4根抛竿打不同位置，大鱼一天可能只来一口。

**FishOn-S3 使用流程**：
```
06:00 — 架竿，安装子机
06:15 — 进入"守大物模式"（设置 → 大物模式）
         — 灵敏度自动降低（过滤小鱼）
         — 大鱼判定阈值调高
...
10:30 — 竿2 黄色闪烁→ 持续2秒后自动消失（小鱼闹窝，过滤）
         屏幕显示竿2信号衰减图
...
14:45 — 竿4 🔴🔴🔴 爆口！幅度5.2g！
         — 紧急提示音（区别于普通中鱼）
         — 屏幕震动指示
         — 自动推送飞书："🔴 大鱼！竿4 14:45"
         跑到竿前 → 搏斗15分钟 → 20斤青鱼上岸
         触摸[标记渔获] → "青鱼约20斤"
...
16:00 — 继续守
         竿1 竿3 各中一条5-8斤鱼
         全部记录
```

**对比没有 FishOn-S3**：
- ❌ 大鱼慢口一整天，盯一天竿熬不住
- ❌ 错过唯一的爆口机会
- ❌ 尺寸/时间无法精确记录

---

### 场景三：筏钓/桥钓 🚣

**背景**：在渔排或桥上钓，竿多且空间紧凑，竿梢细微抖动很难凭肉眼判断。

**FishOn-S3 使用流程**：
```
— 筏竿较短，子机贴在竿梢根部
— 灵敏度设为"高"（筏竿抖动幅度小）
— 屏幕放在手边看
— 鱼口：屏幕会先显示细微波形变化
   → 随后竿梢才有肉眼可见抖动
   → **比肉眼提前 1-2 秒发现鱼口**
```

**核心优势**：IMU 比肉眼更灵敏，提前 1-2 秒发现鱼口，这 2 秒决定能不能及时刺鱼。

---

### 场景四：坐钓休闲 🏕️

**背景**：周末公园湖边坐钓，2-3根竿，一边钓鱼一边玩手机/看书/聊天。

**FishOn-S3 使用流程**：
```
— 拿出 CoreS3 SE
— 不装子机，直接用 CoreS3 SE 自带的 MPU6886
— 把 CoreS3 SE 夹在竿架上或放竿旁
— 竿梢振动通过竿体传到 CoreS3 SE
— 凑合用，精度比子机差但不用额外硬件
```

**简化场景**：最低配置方案，一个 CoreS3 SE 就够了，不需要额外买任何东西。

## 六、数据与日志

```csv
时间,竿号,事件,幅度(g),频率(Hz),鱼种(标记),温度,气压
2026-04-28 14:45:02,竿2,小鱼闹窝,0.45,8.2,,24℃,1013hPa
2026-04-28 14:45:14,竿2,消失,,,,,
2026-04-28 19:20:33,竿3,中鱼,2.15,6.7,鲤鱼,22℃,1010hPa
2026-04-28 19:21:48,竿3,标记渔获,2.15,6.7,鲤鱼(3斤),,
2026-04-28 19:24:00,竿3,复位,,,,,
```

### 6.2 统计指标

- 今日鱼口数 / 中鱼数 / 上岸数
- 各竿上鱼率
- 最佳上鱼时段（自动统计）
- 不同天气/气压下的鱼口活跃度
