## 一、产品概述

### 1.1 一句话定义
**一套基于 M5StickC Plus 的多竿智能鱼口监控系统。竿梢子机本地 IMU 分析振动，BLE 无线传结论，StickC 放帐篷里/夹竿上，蜂鸣器叫醒你区分大鱼小鱼。**

### 1.2 核心设计理念
```
竿梢子机本地算鱼口，BLE 只是快递员。
StickC 只负责显示和响铃，不参与计算。
```

### 1.3 解决的核心痛点
| 痛点 | 解决方案 |
|:----|:---------|
| 海竿阵8根竿看不过来 | StickC 屏幕一目了然 |
| 夜钓/帐篷睡觉怕错过 | 蜂鸣器叫醒，不用担心 |
| 分不清小鱼闹窝还是大鱼 | 子机本地IMU分析，不同节奏提醒 |
| 单竿出钓还要额外硬件 | StickC 直接夹竿上用，自带IMU |
| 成品无线报警器太贵 | DIY子机 ¥12/竿，8竿才 ¥100 |

### 1.4 为什么是 M5StickC Plus 而不是 CoreS3 SE

| 决策点 | CoreS3 SE | **M5StickC Plus ✅** |
|:------|:---------|:-------------------|
| 已有 | 你没有（需¥360买） | **你手边就有 ≈ ¥0** |
| 触控 | 需要 | **不需要（看竿号就行）** |
| 屏幕 | 1.9" 适合仪表盘 | **1.14" 足够显示竿状态** |
| 喇叭 | 好 | **蜂鸣器够用（响就行）** |
| 单竿模式 | 太大，夹竿上累赘 | **细长条，直接夹竿上** |
| 便携 | 方盒子 | **放口袋/帐篷都行** |
| IMU | MPU6886 同款 | **MPU6886 同款** |

**结论：StickC 功能够用，价格免费，便携性更好。CoreS3 SE 的触摸/喇叭/WiFi 在这个项目里用不上。**

## 二、系统架构

### 2.1 数据流

```
竿梢子机 (ESP32-C3 + MPU6050)     ← 每个竿贴一个
  │
  │ ① MPU6050 以 100Hz 采样加速度
  │ ② 子机本地计算振动特征：
  │    - 实时幅度（当前值 - 静止基准）
  │    - 频率估计（过零检测）
  │    - 持续时间计时
  │ ③ 判断结论通过 BLE 广播出去
  │    广播包仅 4 字节：
  │    { 竿ID(1B), 状态码(1B), 幅度(1B), 电量(1B) }
  │    一次广播 < 1ms
  │
BLE ─────────── 无线 ──────────
  │
  ▼
M5StickC Plus（主机）                ← 放帐篷/口袋里
  │
  │ ④ 扫描 BLE 广播包
  │ ⑤ 解析：竿3 → 状态=爆口 → 幅度=4.2g
  │ ⑥ 屏幕显示竿号 + 🔴 红色
  │ ⑦ 蜂鸣器紧急节奏叫醒你
  │
  │ StickC 不参与任何鱼口计算
  │ 只做显示和报警
```

### 2.2 两种工作模式

```
模式 A：多竿模式（帐篷/车里睡觉 🏕️）
┌────────────────────────────────────┐
│  StickC 放枕头边                    │
│  BLE 扫描 1-8 个子机               │
│  鱼口→ 蜂鸣器响 → 出去收竿        │
│    │                               │
│  BLE                                │
│    │                                │
│  ┌──┴──┐  ┌──┴──┐      ┌──┴──┐    │
│  │竿1  │  │竿2  │      │竿8  │    │
│  │子机 │  │子机 │ ...  │子机 │    │
│  │¥12  │  │¥12  │      │¥12  │    │
│  └─────┘  └─────┘      └─────┘    │
└────────────────────────────────────┘

模式 B：单竿模式（直接夹竿上 🎣）
┌────────────────────────────────────┐
│  竿梢 ── StickC（夹在竿节上）      │
│              │                     │
│        自有MPU6886 检测振动        │
│        检测到 → 蜂鸣器响           │
│        ★ 0 额外硬件 ★              │
└────────────────────────────────────┘
```

### 2.3 成本弹性

```
            今天带1根竿 → StickC夹上         ¥0
            今天带3根竿 → StickC + 2子机     ¥24
            今天带8根竿 → StickC + 7子机     ¥84
```

不像成品套装焊死4竿，子机按需配。

## 三、核心功能定义

### 3.1 竿梢子机：鱼口检测算法

**IMU 本地分析设计原则**：竿梢子机独立完成判断，BLE 只传结论。

```
竿梢抖动
  │
  ▼
MPU6050 采样 (100Hz)
  │
  ├─ 时域特征提取
  │   ├─ 峰值幅度（max - min）/ 窗口
  │   ├─ 振动能量（幅值平方积分）
  │   ├─ 过零频率（每秒穿越零点的次数）
  │   └─ 衰减速率（峰值下降速度）
  │
  ├─ 模式分类
  │   ┌──────────────────────────────────────────┐
  │   │ 幅度 < 0.3g         → 静默/风浪          │ ← 不广播，省电
  │   │ 幅度 0.3-1.2g       → 小鱼闹窝           │ ← BLE 🟡
  │   │ 幅度 1.2-3.5g + 持续 >2s → 中鱼         │ ← BLE 🔴
  │   │ 幅度 >3.5g 瞬时爆发 → 大鱼爆口          │ ← BLE 🔴🔴
  │   │ 频率 >20Hz          → 水流/风误报        │ ← 过滤
  │   └──────────────────────────────────────────┘
  │
  ├─ 状态机驱动 BLE 广播
  │
  └─ 子机深睡功耗 ~10μA（竿不动时）
```

### 3.2 主机 StickC：报警输出

| 鱼口类型 | BLE 状态码 | 屏幕显示 | 蜂鸣器节奏 | 含义 |
|:--------|:----------|:--------|:----------|:-----|
| 待命 | 0x00 | 🟢 竿N | 静音 | 一切正常 |
| 小鱼闹窝 | 0x01 | 🟡 竿N 可疑 | 短促「哔」×1 | 瞟一眼就行 |
| 中鱼 | 0x02 | 🔴 竿N 中鱼！ | 持续「哔——」×3 | 去收竿 |
| 爆口 | 0x03 | 🔴🔴 竿N 爆口！ | 高频「哔哔哔！」 | 丢下一切跑过去 |
| 离线 | 0xFF | ⚫ 竿N 离线 | 每10秒「哔」 | 检查电池/距离 |

**鱼口状态机**：

```
                ┌──────────┐
                │  待命中  │ ← 上电/复位
                └────┬─────┘
                     │ 收到 BLE 包
                     ↓
                ┌────────────┐
         ┌─────│ 可疑(0x01)  │──────┐
         │     └─────┬──────┘      │
         │       持续包          单次后消失
         │           │              │
         ↓           ↓              ↓
    ┌───────┐ ┌───────────┐  ┌──────────┐
    │小鱼闹窝│ │中鱼(0x02) │  │ 误报过滤 │
    │🟡+短哔 │ │🔴+持续哔  │  │ 忽略     │
    └───────┘ └─────┬─────┘  └──────────┘
                    │ 爆口(0x03)
                    ↓
              ┌───────────┐
              │ 紧急报警   │ ← 最高优先级
              │ 🔴🔴+高频  │
              └─────┬─────┘
                    │ 用户手动静音
                    ↓
              ┌───────────┐
              │  待命中    │ ← 自动复位
              └───────────┘
```

### 4.3 接线图

```
ESP32-C3                    MPU6050
┌───────┐                  ┌──────┐
│ 3.3V  ├──────────────────┤ VCC  │
│ GND   ├──────────────────┤ GND  │
│ GPIO5 ├──────────────────┤ SCL  │
│ GPIO6 ├──────────────────┤ SDA  │
└───┬───┘                  └──────┘
    │
    ├── CR2032 电池座 (+)
    └── 开关
```

**只需 4 根线，10 分钟焊一个。** 焊完包热缩管，小手指大小。

### 4.4 功耗

| 状态 | 电流 | CR2032(230mAh)续航 | 触发条件 |
|:----|:----|:-----------------|:--------|
| 深睡 | ~10μA | **~2年** | 竿梢静止 |
| 检测 | ~15mA | ~15小时 | 有振动 |
| BLE广播 | ~20mA | ~11小时 | 检测到鱼口 |

**正常出钓一次 8-10 小时，全程活跃也没问题。** 平时深睡待机两年。

## 六、使用场景

### 场景一：帐篷睡觉守海竿阵 🌙🔥

**装备**：StickC + 7个子机（¥84）

```
23:00 — 架8根海竿，7根装子机，1根装StickC（单竿模式）
23:05 — StickC 切多竿模式，放枕头边
23:10 — 睡觉 💤
...
02:30 — 竿4 🔴🔴 爆口！高频蜂鸣叫醒
         → 屏幕显示"竿4 爆口！幅度4.2g"
         → 出帐篷收竿 → 大青鱼上岸
         → 按A键静音 → 复位
02:40 — 继续睡
...
05:00 — 竿2 🔴 中鱼！持续蜂鸣
         → 鲤鱼一条
05:05 — 标记后继续
...
06:30 — 日出，起床收竿
         → 查看记录：青鱼×1, 鲤鱼×2, 鲫鱼×3
         → 小鱼闹窝过滤×15次（没吵醒你）
```

**你获得的**：踏实睡一整夜，只在大鱼上钩时被叫醒。小鱼闹窝？屏上闪一下黄灯，不会吵你。

### 场景二：单竿坐钓 🎣

**装备**：StickC 一根（¥0）

```
— StickC 夹在竿梢附近竿节上
— 按B键切单竿模式
— 自己IMU检测抖动
— 大鱼→"哔——"持续响；小鱼→"哔·"短促一声
— 手机玩着，来了就收竿
— 收工回家，不拆任何额外设备
```

### 场景三：岸边多竿 🐟

**装备**：StickC + 2个子机（¥24）

```
— 3根竿，2根装子机
— StickC 放岸边石头/钓箱上
— 不用一直盯着水面看竿梢
— 刷刷抖音/喝喝茶，鱼来了蜂鸣器告诉你
```

## 九、技术栈

| 层 | 技术 |
|:---|:-----|

| IDE | **PlatformIO** / Arduino IDE |

### BLE 通信协议

```
子机广播数据 (4 bytes)：
┌────────┬────────┬────────┬────────┐
│ Byte 0 │ Byte 1 │ Byte 2 │ Byte 3 │
├────────┼────────┼────────┼────────┤
│ 竿ID   │ 状态码 │ 幅度   │ 电量%  │
│ 0-7    │ 0-3    │ 0-100  │ 0-100  │
└────────┴────────┴────────┴────────┘

状态码：
0 = 待命     1 = 可疑(小鱼)
2 = 中鱼     3 = 爆口
```
