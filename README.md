# 🎣 FishOn-S3 — 多竿智能鱼口监控系统

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**基于 M5StickC Plus + DIY BLE 子机的多竿鱼口监控系统。** IMU 传感器本地分析振动模式，BLE 无线传结果到主机，屏幕 + 蜂鸣器区分大鱼/小鱼，帐篷车里睡觉也能知道哪根竿中鱼了。

```
          🏕️ 帐篷 / 车里
              │
         M5StickC Plus         ← 主机（你已有）
              │ BLE 广播
    ┌─────────┼─────────┐
    │ 竿1     │ 竿2     │ ... 竿8
 子机(¥12) 子机(¥12)    子机(¥12)
```

## ✨ 特性

- **一机两用** — 多竿模式当主机接收器 / 单竿模式直接夹竿上自用
- **多竿监控** — 1 个 StickC 同时监控 8 根竿
- **智能鱼口识别** — 竿梢子机本地 IMU 分析，区分大鱼咬钩 vs 小鱼闹窝
- **蜂鸣报警** — 不同节奏区分大鱼/小鱼/爆口
- **单竿免子机** — StickC 自带 IMU，一根竿直接夹上用
- **渔获日志** — 记录每次中鱼时间、竿号
- **按需配置** — 今天带几根竿就装几个子机

## 🏗️ 系统架构

### IMU 本地分析，BLE 只传结论

```
竿梢子机 (ESP32-C3 + MPU6050)
  │
  │ ① MPU6050 100Hz 采样加速度
  │ ② 子机本地计算振动幅度/频率
  │ ③ 判断结果通过 BLE 广播
  │    => 只传 4 字节：{ 竿ID, 状态, 幅度, 电池 }
  │
BLE  一次广播 < 1ms
  │
  ▼
M5StickC Plus（主机）
  │
  │ ④ 扫描 BLE 包 → 解析
  │ ⑤ 屏幕显示竿号 + 状态
  │ ⑥ 蜂鸣器按不同节奏报警
```

### 两种工作模式

```
模式一：多竿（帐篷睡觉 🏕️）        模式二：单竿（直接夹竿上 🎣）
  ┌────────────┐                  ┌────────────────┐
  │ StickC     │   BLE            │ StickC         │
  │ 放枕头边 ──┼── 竿1子机(¥12)  │ 夹在竿梢处     │
  │ 屏幕显示   │   BLE            │ 自身MPU6886    │
  │ 蜂鸣器响   ──┼── 竿2子机(¥12) │ 检测竿梢抖动   │
  │            │   ...            │ 振动就响       │
  │            ──┼── 竿8子机(¥12) │ 0 额外硬件     │
  └────────────┘                  └────────────────┘
```

### 鱼口状态机（子机本地执行）

```
竿梢静止 ──→ 深睡 (10μA)
   │              │
   │ 竿梢抖动    │ 安静 >5s
   ▼              │
检测中 ──→ 幅度<0.3g ──→ 小鱼闹窝 → BLE{黄灯, 低频提醒}
   │                        
   │ 幅度0.3-1.5g 持续>2s
   ├──→ 中鱼 → BLE{红灯, 持续蜂鸣}
   │
   │ 幅度>4g 瞬间爆发
   └──→ 爆口 → BLE{红灯闪烁, 紧急蜂鸣}
```

## 🎣 使用场景

### 场景一：帐篷睡觉守大鱼 🏕️🔥

```
23:00 — 架好8根海竿，装子机，StickC放枕头边
02:30 — 竿4爆口！蜂鸣器紧急响 → 起来收竿，20斤青鱼
02:35 — 标记渔获，继续睡
05:00 — 竿2中鱼 → 蜂鸣器响（不同节奏）→ 鲤鱼一条
05:05 — 标记，继续
```

**价值点**：不用熬夜盯着，放心睡，鱼来了叫你。**一个 StickC + 几个 ¥12 子机，比花 800 买无线报警套装值。**

### 场景二：单竿出钓 🐟

```
— StickC 直接夹竿梢上
— 自带 MPU6886 检测抖动
— 大鱼持续哔——，小鱼间断哔·哔·哔
— 完全不需要额外硬件
```

### 场景三：岸边坐钓多竿 🌙

```
— StickC 放脚边
— 3个子机贴竿上
— 不用盯着水面看竿梢
— 刷刷手机，鱼口来了蜂鸣器叫
```
